The funniest one-line error message an AI agent shows when it runs out of tokens mid-sentence. The joke is self-referential: the error message itself runs out of tokens while explaining that it ran out of tokens, and breaks off mid-word.

## Run it

```sh
python3 main.py
```

This writes the entry line to `$OUTPUT_DIR/entry.txt` (default `/output`). Pure Python standard library, deterministic — two runs produce byte-identical files.
